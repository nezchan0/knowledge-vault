What's new: nothing yet — this is the bare-bones formula.

Five rooms plus "outside" (room 5, the goal). Every step: stand in a room, pick a uniformly random valid door, walk through it, and update one Q-table cell with Q(s,a) = R(s,a) + γ·max Q(s′,·) — a straight replacement, no learning rate, no smarter action choice yet.

What's new: ε (epsilon)-greedy action choice, decaying every episode.

Same rooms, same doors, same reward matrix. The only change: instead of always picking a random door, the agent now rolls against ε each step — random below it, "walk to the door with the best known Q-value" above it. ε starts at 1.0 (all exploring) and shrinks after every episode, so the path sharpens over time. The update formula is unchanged (α is still effectively 1) — written here with the subtraction spelled out so Level 3's change is easy to spot.

What's new: α (alpha) learning rate — and a noisy reward to justify needing it.

The door to "outside" no longer always pays exactly 100. Each time the agent walks out, it actually receives 100 ± noise — same door, different payout every time. Two agents watch the same walk and the same noisy paycheck: one uses α = 1 (Level 1/2's behavior — fully trust the newest number), the other uses your adjustable α (blend the new number into what it already believed). Watch which one's Q-value jitters and which one settles.
