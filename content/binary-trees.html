🌳 Binary Trees - Fundamentals and Traversals

Binary Trees are one of the most important data structures in Computer Science. They are used in search algorithms, databases, file systems, compilers, heaps, binary search trees, AVL trees, segment trees, and many interview problems.

Before learning advanced trees like BSTs, AVL Trees, Red-Black Trees or Tries, it is essential to understand how a simple Binary Tree works.

  • Solve beginner Binary Tree interview questions.

What is a Binary Tree?

Definition

A Binary Tree is a hierarchical data structure in which every node has at most two children. These children are called

  • Left Child
  • Right Child
No node can have more than two children.

Example Binary Tree



                A
              /   \
             B     C
            / \   / \
           D   E F   G

Here,

  • Root = A
  • Parent of D = B
  • Children of C = F, G
  • Leaf Nodes = D, E, F, G
  • Total Nodes = 7
  • Total Edges = 6

Basic Terminology

Term Description
Root The first node of the tree.
Parent A node having children.
Child Node directly connected below another node.
Leaf Node Node with no children.
Internal Node Node having at least one child.
Sibling Nodes sharing the same parent.
Edge Connection between two nodes.
Path Sequence of connected nodes.
Depth Distance from root to a node.
Height Longest distance from node to any leaf.
Level Position of a node in the tree.

Height vs Depth

Depth

Number of edges from the root to a node.

Height

Number of edges in the longest path from a node to a leaf.

⚠ Interview Warning

Some books define height as the number of nodes, while most interview problems define it as the number of edges. Always verify the definition being used.

🌲 Tree Traversals (Depth First Search)

Traversal means visiting every node of a tree exactly once. Since trees are non-linear data structures, we need systematic algorithms to visit all nodes.

The first category of traversals is called Depth First Search (DFS). DFS explores one branch completely before moving to another branch.

📘 Depth First Search (DFS)

DFS goes as deep as possible into one subtree before backtracking and exploring another subtree.

DFS can be implemented using:

  • Recursion (most common)
  • Stack (iterative implementation)

Example Tree



                A
              /   \
             B     C
            / \   / \
           D   E F   G

We will use this same tree for every traversal.

1️⃣ Preorder Traversal

Traversal Order

Root → Left → Right
💡 Memory Trick

Meet yourself first, then visit your left child, then your right child.

Recursive Algorithm

def preorder(root):

    if root is None:
        return

    print(root.val, end=" ")

    preorder(root.left)

    preorder(root.right)

How it Works

  1. Visit current node.
  2. Traverse left subtree.
  3. Traverse right subtree.
🎯 Interview Tip Preorder is commonly used for:
  • Tree Serialization
  • Copying Trees
  • Creating Prefix Expressions

Iterative Preorder

Instead of recursion, we use a Stack. 

def preorder(root):

    if root is None:
        return

    stack = [root]

    while stack:

        node = stack.pop()

        print(node.val, end=" ")

        if node.right:
            stack.append(node.right)

        if node.left:
            stack.append(node.left)
💡 Push the right child first. Since Stack is LIFO, the left child gets processed first.

Complexity

Operation Complexity
Time O(n)
Space O(h)

Recursive Algorithm

def inorder(root):

    if root is None:
        return

    inorder(root.left)

    print(root.val, end=" ")

    inorder(root.right)

Iterative Inorder

def inorder(root):

    stack = []

    current = root

    while current or stack:

        while current:

            stack.append(current)

            current = current.left

        current = stack.pop()

        print(current.val, end=" ")

        current = current.right
🎯 Most Important Interview Fact If the tree is a Binary Search Tree (BST), Inorder Traversal always produces the elements in sorted order. This fact appears in countless coding interviews.

Complexity

Operation Complexity
Time O(n)
Space O(h)

Recursive Algorithm

def postorder(root):

    if root is None:
        return

    postorder(root.left)

    postorder(root.right)

    print(root.val, end=" ")

Iterative Postorder (Two Stacks)

def postorder(root):

    if root is None:
        return

    stack1 = [root]
    stack2 = []

    while stack1:

        node = stack1.pop()

        stack2.append(node)

        if node.left:
            stack1.append(node.left)

        if node.right:
            stack1.append(node.right)

    while stack2:

        print(stack2.pop().val, end=" ")
🎯 Interview Tip Postorder is commonly used for:
  • Deleting Trees
  • Freeing Memory
  • Evaluating Expression Trees

Complexity

Operation Complexity
Time O(n)
Space O(h)

📊 DFS Traversal Comparison

Traversal Order Main Uses
Preorder Root → Left → Right Serialization, Copy Tree, Prefix Expression
Inorder Left → Root → Right Sorted order in BST
Postorder Left → Right → Root Delete Tree, Expression Evaluation

⚠ Common Mistakes

  • Confusing Height with Depth.
  • Writing Root before Left in Inorder.
  • Pushing left child first in iterative preorder.
  • Forgetting the base case (if root is None).
  • Mixing preorder and postorder sequences.

🌊 Breadth First Search (BFS)

Unlike DFS, which explores one branch completely before moving to another, Breadth First Search (BFS) visits nodes level by level.

📘 Breadth First Search (BFS)

BFS visits every node on the current level before moving to the next level.

It uses a Queue (FIFO).

💡 Memory Trick

DFS → Stack / Recursion
BFS → Queue

Example Tree



                A
              /   \
             B     C
            / \   / \
           D   E F   G

Traversal Order



A

↓

B C

↓

D E F G

Output



A B C D E F G

Queue Visualization

Understanding the queue makes BFS extremely easy.

Queue Visited
[A] -
[B,C] A
[C,D,E] A B
[D,E,F,G] A B C
[E,F,G] A B C D

Python Implementation

from collections import deque

def level_order(root):

    if root is None:
        return

    queue = deque([root])

    while queue:

        node = queue.popleft()

        print(node.val, end=" ")

        if node.left:
            queue.append(node.left)

        if node.right:
            queue.append(node.right)
🎯 Interview Tip Whenever you hear
  • Level Order Traversal
  • Print Tree Level by Level
  • Shortest Path in an Unweighted Graph
Immediately think Queue + BFS

Complexity

Operation Complexity
Time O(n)
Space O(n)

The queue may contain an entire level of the tree, making the worst-case space complexity O(n).

🏁 Key Takeaways

  1. Every Binary Tree node has at most two children.
  2. Height is the longest path from a node to a leaf.
  3. Depth is the distance from the root to a node.
  4. Preorder visits the root first.
  5. Inorder visits the root in the middle.
  6. Postorder visits the root last.
  7. Level Order Traversal uses a Queue.
  8. DFS uses Recursion or a Stack.
  9. All traversals have O(n) time complexity.
  10. Understanding Binary Trees is the foundation for BSTs, AVL Trees, Heaps, Tries, and many advanced data structures.
