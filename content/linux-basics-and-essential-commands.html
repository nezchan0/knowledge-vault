Linux Basics and Essential Commands

Linux is an operating system built around a hierarchical filesystem and powerful command-line tools. Most development servers, cloud machines, containers, and DevOps environments run Linux, making terminal proficiency an important skill for developers.

In Linux, almost everything is treated as a file, including devices, directories, and system resources. The command line allows users to interact with these resources efficiently.

Understanding the Filesystem

The Linux filesystem starts at the root directory:

/

Common directories:

  • /home — user home directories
  • /etc — configuration files
  • /var — logs and variable data
  • /usr — installed programs and libraries
  • /tmp — temporary files
  • /root — home directory of the root user

Checking Current Directory

Use pwd (Print Working Directory) to see your current location: 

pwd

Example Output:

/home/sanya/projects

Listing Files and Directories

Basic Listing

ls

Shows files and folders in the current directory.

Detailed Listing

ls -l

Displays permissions, owner, size, and modification date.

Show Hidden Files

ls -a

Files beginning with . are hidden by default.

Detailed + Hidden

ls -la

Changing Directories

Move to a Directory

cd /path/to/folder

Example:

cd /home/sanya/projects

Go to Home Directory

cd

or

cd ~

Go Back One Directory

cd ..

Go Back Two Directories

cd ../..

Go to Previous Directory

cd -

Creating Files

Create an Empty File

touch file.txt

Create multiple files:

touch file1.txt file2.txt file3.txt

Viewing File Contents

Display Entire File

cat file.txt

View Beginning of File

head file.txt

View End of File

tail file.txt

Writing Text to Files

Print Text

echo "Hello Linux"

Create File with Text

echo "Hello Linux" > file.txt

The > operator overwrites the file.

Append Text

echo "New Line" >> file.txt

The >> operator appends content.

Creating Directories

Create Single Directory

mkdir myfolder

Create Multiple Directories

mkdir folder1 folder2 folder3

Create Nested Directories

mkdir -p projects/python/django

The -p flag creates missing parent directories automatically.

Copying Files

Copy File to Another Directory

cp file.txt /home/sanya/backup/

Copy and Rename Simultaneously

cp file.txt copy.txt

Copy Multiple Files

cp file1.txt file2.txt destination/

Copying Directories

Without -r

cp myfolder backup/

This fails because Linux does not copy directories recursively by default.

With Recursive Flag

cp -r myfolder backup/

The -r flag copies the directory and all its contents.

Moving Files and Directories

Move File

mv file.txt destination/

Rename File

mv old.txt new.txt

Move Directory

mv project/ backup/

Removing Files

Delete a File

rm file.txt

Delete Multiple Files

rm file1.txt file2.txt

Removing Directories

Remove Empty Directory

rmdir myfolder

This only works if the directory is empty.

Remove Directory and Contents

rm -r myfolder

Force Remove Directory

rm -rf myfolder

Be extremely careful with rm -rf. It permanently deletes files without sending them to a recycle bin.

Searching for Files

Find a File

find . -name "file.txt"

Find Python Files

find . -name "*.py"

Searching Inside Files

Using grep

grep "Django" notes.txt

Case-Insensitive Search

grep -i "django" notes.txt

File Permissions

View permissions:

ls -l

Example:

-rw-r--r-- 1 user user 500 file.txt

Permission groups:

  • User (owner)
  • Group
  • Others

Make Script Executable

chmod +x script.sh

Useful Developer Commands

Clear Terminal

clear

Command History

history

Check Current User

whoami

Check System Information

uname -a

Check Disk Usage

df -h

Check Folder Size

du -sh myfolder

Wildcards

List All TXT Files

ls *.txt

Delete All Log Files

rm *.log

Redirection and Pipes

Save Output to File

ls > files.txt

Append Output

ls >> files.txt

Pipe Output to Another Command

ls -la | grep ".txt"

The pipe operator | sends output from one command as input to another.

Key Takeaways

  1. pwd shows the current directory.
  2. ls lists files and folders.
  3. cd is used for navigation.
  4. touch creates files.
  5. mkdir creates directories.
  6. mkdir -p creates nested directory structures.
  7. cp copies files.
  8. cp -r copies directories recursively.
  9. mv moves and renames files.
  10. rm deletes files.
  11. rm -r removes directories.
  12. grep searches file contents.
  13. find searches for files.
  14. chmod changes permissions.
  15. Mastering these commands forms the foundation for Linux development, DevOps, cloud computing, and backend engineering.
